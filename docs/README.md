## ⚠️ 보안 주의사항

### 절대 하지 말 것
- ❌ Github 등 공개 저장소에 키 커밋
- ❌ 채팅창에 키 그대로 붙여넣기
- ❌ 카카오톡/메일로 키 공유

### 해야 할 것
- ✅ **Streamlit Secrets**에 직접 입력 (배포 시)
- ✅ 로컬 개발용은 `.streamlit/secrets.toml` (gitignore됨)
- ✅ 팀원 공유 시 비밀번호 매니저(1Password 등) 사용
- ✅ 페북 토큰은 60일마다 갱신 (또는 시스템 사용자 토큰 사용)

---

## 🛠️ 발급 후 다음 단계

1. **팀원 한 명**(또는 본인)이 Streamlit Cloud에 GitHub repo 연결
2. Streamlit Cloud의 **Secrets 탭**에 위 정보 입력
3. 앱 실행 → 비밀번호 입력 → 보고서 생성 테스트

## ❓ 자주 묻는 질문

**Q. 한 번에 다 발급받기 너무 빡세요. 부분만 가능?**
- 구글 시트 + 페북만 있어도 일단 작동 (네이버는 누적용)
- 단, 매칭이 안 되니 광고비/매출 별도로 조회만 가능

**Q. 네이버 커머스 API는 이미 있는데 어떤 정보가 필요한가요?**
- `Client ID`, `Client Secret`, `판매자 ID(스마트스토어)` 3가지
- 권한에 **"주문 조회"** 포함되어 있어야 함

**Q. 페북 토큰이 60일마다 만료되는 게 부담인데?**
- **시스템 사용자 토큰(System User Access Token)**으로 발급하면 무기한
- 가이드 1번 6단계 참고

**Q. 발급 도중 막히면?**
- 각 가이드 하단 **트러블슈팅** 섹션 확인
- 막히는 단계 스크린샷 찍어서 Claude에게 물어봐도 OK
